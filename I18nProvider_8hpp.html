Detailed Description

Static translation table builder for supported UI languages.

Centralises all user-visible string literals so that adding a new locale requires changes to exactly one translation unit (I18nProvider.cpp) and nowhere else. UiViewModel delegates to this class instead of hosting the string tables directly.
