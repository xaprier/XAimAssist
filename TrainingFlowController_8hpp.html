Detailed Description

Owns the training session state machine and all associated timers, pipeline-timing diagnostics, and EventBus subscriptions.

Extracted from Application::Run() to give the training flow a single, testable home. Application::Run() constructs this class, calls Initialize(), and delegates all session-related behaviour through it.

Lifecycle:

  1. Construct with Deps.
  2. Call Initialize() — wires UI callbacks, input handlers, EventBus subs.
  3. Application runs the Qt event loop.
  4. Call Stop() during QCoreApplication::aboutToQuit.
