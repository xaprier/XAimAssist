Detailed Description

Subscribes to shot/target/session events and maintains per-session accumulators for score, accuracy, reaction time, etc.

Periodically publishes RealtimeStatsEvent and, on session end, a SessionSummaryEvent.

Warning
THREAD SAFETY REQUIREMENT StatTracker is NOT thread-safe. All event callbacks must be invoked from the same thread (typically the Qt main event loop thread). EventBus handlers are invoked synchronously on the publisher's thread, so ensure all Publish() calls originate from the main thread.

Debug builds include thread assertions to detect violations.

Note
If multi-threaded event publishing is required in the future, add mutex protection around m_sessions and m_performanceAccumulator.
